# Согласие на использование изображения гражданина

## Назначение

Скилл готовит форму согласия человека на обнародование и использование его изображения (фото, видео, рисунок) в продукте, сторах и рекламе: для сотрудников на странице «Команда», клиентов в отзывах и кейсах, моделей, участников мероприятий и вебинаров, авторов фото, которые владелец хочет использовать в маркетинге. Плюс таблица учёта оснований по каждому изображению.

Это гражданско-правовое правило без надзорного органа (`ru:izobrazhenie-grazhdanina-v-kontente`). Если по изображению можно определить человека и оно публикуется для неопределённого круга лиц, может понадобиться и согласие на распространение ПДн — по шаблону `soglasie-na-rasprostranenie-pdn` (`ru:soglasie-na-rasprostranenie-pdn`).

## Основания

- `ru:izobrazhenie-grazhdanina-v-kontente` — согласие на изображение, исключения, удаление из интернета, частная жизнь (ГК ст. 152.1, 152.2; Пленум ВС № 25).
- `ru:soglasie-na-rasprostranenie-pdn` — отдельное согласие на распространение ПДн (152-ФЗ ст. 10.1).
- `ru:biometriya-pri-autentifikacii` — изображение для установления личности.
- `ru:licenzionnoe-soglashenie-s-polzovatelem-eula` — права на сами фотографии пользователей (лицензия на контент).

## Что найти при запуске

- Из разведки: страницы с фото и видео людей («Команда», отзывы, кейсы, баннеры, карточки сторов), загрузка фото пользователями, записи вебинаров, функции распознавания лиц.
- От владельца: чьи это изображения (сотрудники, клиенты, модели, сток), есть ли договоры с моделями и фотографами.
- Структуру формы согласия доисследовать по research-rules (только структура, текст не копировать).

## Кто подписывает и подаёт

Подписывает изображённый человек; после его смерти — лица из ст. 152.1 п. 1. Согласие хранит владелец продукта (бремя доказывания на использующем — трактовка по Пленуму ВС № 25). Никуда не подаётся.

## Спорные места

- Нужно ли оформлять и согласие по ГК, и согласие на распространение ПДн, или одно покрывает другое, — не разъяснено; по ГК согласие может быть конклюдентным, по 152-ФЗ молчание согласием не считается.
- Сгенерированные ИИ изображения, похожие на реального человека, не рассматривались.
- Голос: нормы об охране голоса в ГК нет; голос — ПДн (вывод), биометрией становится только при использовании для установления личности. Является ли вебинар с регистрацией «публичным мероприятием» — нормативного ответа нет.
- Права фотографа на снимок не заменяют согласие изображённого (вывод).
